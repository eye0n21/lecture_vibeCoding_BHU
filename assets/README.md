# 시작하기 — 읽는 데 1분

이 폴더가 팀의 작업 폴더입니다. 폴더 이름을 "조이름_아이템명"으로 바꾼 뒤 시작하세요. (예: 약손_오늘약)

## 순서

1. VS Code를 열고 "파일 → 폴더 열기"로 이 폴더를 엽니다.
2. 왼쪽 아이콘 중 Claude Code를 눌러 채팅창을 엽니다. 로그인이 풀려 있으면 다시 로그인합니다.
3. 미리 준비하면 좋은 것 (안 해도 시작은 됩니다)
   - 기획서.md 0절에 1일차 문제정의서 8번 "최종 문제정의문"을 그대로 붙여 넣기
   - 기획서.md 3절 표에 2일차에 각자 쓴 기능 초안을 모아 적기. 5개 이내, 시연할 기능에 ★ 하나
   - 디자인 방향을 셋 중 하나로 정하기 (아래 "디자인 방향" 참고)
4. 채팅창에 아래 문장을 그대로 붙여 넣습니다.

   claude.md 파일을 읽고 html 페이지 작성 시작해

5. Claude Code가 먼저 기획서.md를 읽고 디자인 방향을 확인합니다. 그다음 1일차 문제정의서 8번 "최종 문제정의문"을 붙여 달라고 합니다(기획서.md 0절에 적어 두었으면 묻지 않습니다). 그 문장을 그대로 붙이세요. 이어서 결과물 유형을 묻습니다 — (가) 앱·서비스 상세를 설명하고 화면 모형을 넘겨 보는 소개 페이지 / (나) 해결안이 웹사이트인 팀은 그 웹페이지 자체 / (다) 소개 + 실제로 눌리는 시연 섹션(샘플 「오늘약」, 기본 추천). 그다음 질문을 6묶음 합니다. 1일차 활동지(캔버스·문제정의서)를 옆에 두고 답하세요. 모르면 "추천해줘"라고 하면 됩니다. 기획서.md에 미리 적어 둔 칸은 다시 묻지 않습니다.
6. 묶음이 끝날 때마다 답이 기획서.md에 적힙니다. 중간에 파일을 열어 봐도 됩니다.
7. 질문이 끝나면 요약을 보여주고 "이대로 만들까요?"라고 묻습니다. 확인하면 제작이 시작됩니다.
8. 단계마다 "브라우저에서 확인하세요"라고 하면, 탐색기에서 index.html을 더블클릭해 열어 보고 "확인했어" 또는 고칠 점을 말합니다.

## 디자인 방향 — 셋 중 하나

- (A) getdesign.md에서 내려받기: 마음에 드는 사이트의 DESIGN.md를 받아 이 폴더에 넣습니다. 방법은 "getdesign_이용안내.md" 참고.
- (B) 참고 페이지 캡처: 비슷하게 만들고 싶은 페이지를 캡처해 "참고" 폴더에 넣습니다. 1~3장이면 충분합니다.
- (C) 대화로 정하기: 아무것도 넣지 않고 시작하면 Claude Code가 질문으로 함께 정합니다.

## 이 폴더의 파일

- CLAUDE.md — 강사가 만든 규칙서. 수정하지 않습니다.
- README.md — 지금 읽는 파일
- 기획서.md — 우리 팀 페이지의 내용이 모이는 곳. 미리 채워도 되고, 인터뷰가 채워 줍니다. 디자인 규칙 파일 DESIGN.md와는 다른 파일
- getdesign_이용안내.md — (A)를 고른 팀용
- 참고/ — (B)를 고른 팀이 캡처를 넣는 곳
- images/ — 직접 찍은 사진을 넣는 곳

## 자주 쓰는 말

- 되돌리기: "방금 변경 취소해줘"
- 막연할 때: "이상해" 대신 "제목이 너무 작아", "색이 병원 같아" 처럼 무엇이 어떻게
- 완성 후: "AI 티 나는 부분 찾아서 고쳐줘"
- 발표 전: "발표 대본 도와줘", "AI 활용 과정 정리해줘"
- 제출 전: "제출 점검해줘"

## 제출

제출 시간이 되면 폴더 전체를 압축해 강사 USB에 넣습니다. index.html이 폴더 바로 안에 있어야 합니다.
