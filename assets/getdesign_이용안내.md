# getdesign.md 이용 안내 — 디자인 방향 (A)를 고른 팀

getdesign.md는 유명 사이트 550여 개의 디자인(색, 글꼴, 간격, 버튼 모양, 반응형 규칙)을 분석해 DESIGN.md 파일로 정리해 둔 사이트입니다. 마음에 드는 사이트의 파일을 받아 우리 폴더에 넣으면, Claude Code가 그 분위기를 참고해 페이지를 만듭니다.

## 순서 (3분)

1. 브라우저에서 getdesign.md 에 접속합니다. 쿠키 안내가 뜨면 "Reject Non-Essential"을 누릅니다.
2. 첫 화면 아래 목록에서 사이트를 고릅니다. 각 줄에 한 줄 설명이 있습니다. 예: Airbnb "따뜻한 산호색 강조, 사진 중심, 둥근 UI" / Oura "따뜻한 종이색, 편집 디자인 느낌의 세리프" / NerdWallet "짙은 초록, 민트" / SAP "흰 바탕, 납작한 파란 띠"
3. 사이트 이름을 누르면 분석 페이지가 열립니다. 오른쪽의 "Download DESIGN.md" 버튼을 누릅니다. (그 옆 npx 명령어는 쓰지 않습니다)
4. 내려받은 DESIGN.md 파일을 우리 팀 폴더(CLAUDE.md가 있는 곳)에 넣습니다. 파일 이름은 DESIGN.md 그대로 둡니다.
5. VS Code로 돌아와 "claude.md 파일을 읽고 html 페이지 작성 시작해"라고 하면, Claude Code가 DESIGN.md를 읽고 (A) 방식으로 진행합니다.

## 고를 때 기준

- 우리 대상자를 생각하세요. 어르신 대상이면 글자가 크고 대비가 높은 사이트(공공기관, 금융, 건강 분야)가 맞고, 청년 대상이면 분위기 있는 브랜드 사이트도 괜찮습니다.
- 설명에 "dark", "near-black"이 있으면 어두운 배경입니다. 발표장 프로젝터에서는 밝은 배경이 더 잘 보입니다.
- 사진 중심("photography-driven")인 사이트는 우리에게 사진이 없으면 허전해집니다. 색과 글꼴이 특징인 사이트가 안전합니다.

## 알아둘 것

- DESIGN.md에는 색·글꼴·간격만 있고 우리 아이템 내용은 없습니다. 내용은 Claude Code가 질문으로 채웁니다.
- Claude Code는 그 사이트를 베끼지 않고 "느낌"만 가져옵니다. 로고나 이름은 쓰지 않습니다.
- 글자 크기는 DESIGN.md보다 우리 대상자 기준이 우선입니다. (CLAUDE.md 규칙)
- 로그인 없이 내려받을 수 있습니다. 결제가 필요한 "Starter Kit", "Catalog Pass"는 쓰지 않습니다.
