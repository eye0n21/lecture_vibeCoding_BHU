# 기능명세서 — 5개 이내로

2일차 강의에서 각자 쓴 초안(기능 3개 + ★ 시연 1개)을 팀 채팅에서 모아, 10:30 설계 확정 때 이 표에 5개 이내로 합칩니다. 기능은 "누가 · 무엇을 누르면 · 무엇이 보이나"로 적어야 Claude Code가 만듭니다. "관리한다", "연결한다"는 기능이 아닙니다. 로그인·결제·지도·문자 발송은 우선순위 칸에 "흉내"라고 적습니다. 오늘 실제로 만들 수 있는 것은 그중 1개입니다.

이 파일이 채워져 있으면 Claude Code가 먼저 읽고 인터뷰 3번 묶음(해결안과 기능)을 건너뜁니다.
