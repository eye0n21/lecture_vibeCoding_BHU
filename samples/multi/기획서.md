# 기획서 — 3조 「오늘약」

인터뷰로 확정한 내용입니다. 바꾸고 싶은 것이 있으면 이 파일을 고치거나 말로 요청하세요.

## 1. 팀과 아이템
- 팀명: 3조
- 아이템 이름: 오늘약
- 한 줄 소개: 약봉투 사진 한 장으로 오늘 먹을 약을 정리하고, 먹었는지 가족이 함께 확인하는 서비스
- 분야·출발 옵션: 헬스케어 · 옵션 C 직접 발굴 (고령자 만성질환·복약관리)

## 2. 대상과 문제
- 주 사용자: 70대 혼자 사는 어르신 (병원 2~3곳, 약 5~6종 복용)
- 함께 쓰는 사람: 다른 지역에 사는 자녀(보호자)
- 가장 큰 불편
  - 병원마다 약봉투가 달라서 아침·저녁에 무엇을 먹어야 하는지 헷갈림
  - 자녀는 전화로 "약 드셨어요?"를 묻는 것 말고는 확인할 방법이 없음

## 3. 해결안과 기능
- 핵심 기능
  1. 약 등록: 약봉투를 보고 약 이름과 먹는 시간(아침·점심·저녁)을 큰 글자로 등록
  2. 오늘 복약 체크: 시간대별로 "먹었어요" 버튼 하나만 누르면 끝
  3. 가족 공유: 자녀 화면에 오늘 복약 상태가 바로 보이고, 저녁 8시까지 안 누르면 알림
- 오늘 발표에서 시연할 기능: 2번 오늘 복약 체크 (1번 → 2번 → 3번 순서로 화면을 넘기며 보여줌)
- 운영 주체: 동네 약국 + 구 보건소 (약국에서 첫 등록을 도와주고, 보건소 방문간호 때 확인)
- 기대효과: 복약 누락을 줄이고, 자녀의 전화 확인 부담을 덜어줌

## 4. 페이지 구성
- 선택: 멀티 페이지 (단일 페이지 버전도 비교용으로 함께 제작)
- 페이지 목록
  - index.html — 소개: 어르신의 한 문장, 아이템 한 줄 소개, 문제와 대상
  - feature.html — 기능: 세 가지 기능을 "김순자 어르신의 하루"로 설명
  - demo.html — 시연: 등록 → 오늘 체크 → 가족 화면
  - team.html — 팀: 팀원과 학과별 역할, 운영 주체와 기대효과, AI 활용 과정

## 5. 시연 장면
1. 약 등록 화면: 이미 등록된 약 3개가 보임. "약 추가" 버튼을 누르면 이름과 시간대를 고르는 칸이 나타나고, 추가하면 목록에 붙음
2. 오늘 체크 화면: 아침·점심·저녁 묶음이 세로로 크게. 각 묶음의 "먹었어요"를 누르면 초록색으로 바뀌고 시간이 찍힘
3. 가족 화면: 자녀가 보는 화면. 오늘 체크 결과가 그대로 반영되고, 안 먹은 시간대가 있으면 "저녁 약이 아직이에요" 문구와 전화 버튼이 보임
- 가짜 데이터
  - 어르신: 김순자(74세), 부산 사하구 (가상 동네 "감나무골")
  - 자녀: 박지은(딸, 서울 거주)
  - 약: 혈압약(아침) / 당뇨약(아침·저녁) / 무릎 관절약(저녁) / 위장약(점심)
  - 다니는 병원: 감나무골 내과, 사하 정형외과

## 6. 디자인
- 방식: (C) 대화로 함께 쓰기 → DESIGN.md를 Claude Code가 작성
- 아이템을 떠올리면 생각나는 것: 약봉투, 약국 도장, 약봉투 뒷면 복약 안내표
- 첫 화면의 중심(다른 팀과 달라 보이는 한 가지): SVG로 그린 약봉투. 아침·점심·저녁 칸에 시연과 연동된 "복용" 도장이 찍힘
- 분위기: 약국 안내문처럼 또렷하고 믿음직하게. 꾸밈보다 큰 글자
- 색: 약국 간판의 초록, 도장의 주홍, 종이 흰색. 격자 종이 배경
- 글꼴: 제목은 명조(Noto Serif KR 900), 본문은 Pretendard
- 섹션 장치: 문제는 통화 말풍선, 하루는 가로 시간축, 기능은 복약 안내표, 운영은 동네 지도 선, 팀은 처방전 틀
- 피하고 싶은 것: 병원 홈페이지처럼 메뉴가 많은 것, 작은 글씨, 같은 카드의 반복
