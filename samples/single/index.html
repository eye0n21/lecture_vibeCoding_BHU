김순자 어르신의 하루

기능을 나열하는 대신, 하루를 따라갑니다

오늘약이 있는 날, 어르신과 딸과 방문간호사에게 무엇이 달라지는지 시간 순서로 적었습니다.

  1. 지난주 금요일 · 약국

    약 등록

    약사가 어르신 휴대폰에 오늘약을 열고 약봉투를 보며 혈압약·당뇨약·위장약을 등록합니다. 정형외과 무릎약은 저녁 칸에.

  2. 오전 8시

    아침 약, 버튼 하나

    "아침 약: 혈압약, 당뇨약"이 큰 글씨로 보입니다. 드신 뒤 "먹었어요"를 누르면 도장이 찍히고 8시 12분이 적힙니다.

  3. 낮 12시 반

    점심 약

    위장약 하나뿐인 점심은 자주 빠뜨리던 시간입니다. 점심 칸이 비어 있는 것이 보여서 드시고 누릅니다.

  4. 저녁 7시 · 서울

    딸의 화면

    아침·점심은 도장, 저녁은 "아직". 8시 전이라 알림은 없습니다. 전화를 걸어 묻는 대신 화면을 보고 기다립니다.

  5. 저녁 8시

    체크가 없으면 알림

    8시가 지나도 저녁 칸이 비어 있으면 딸 화면에 "저녁 약이 아직이에요"와 전화 버튼이 뜹니다.

  6. 다음 달 · 보건소

    기록을 함께 보기

    방문간호사가 한 달치 기록을 어르신과 함께 봅니다. 저녁 약이 자주 빠졌다면 복용 시간을 조정하거나 병원에 전달합니다.

복약 안내표처럼 읽는 기능

약봉투 뒷면의 복약 안내표 형식을 빌렸습니다. 오늘 발표에서는 두 번째 줄을 실제로 눌러 보여드립니다.

오늘 체크에서 누른 결과가 가족 화면과 위의 약봉투 도장에 그대로 반영됩니다. 실제 서버 없이 이 페이지 안에서만 동작합니다.

    어머니 오늘 약

    박지은(딸) 화면 · 서울에서 보는 중

    1. 약 등록

    이미 등록된 약 4개가 보입니다. "약 추가"를 누르면 이름과 시간대를 고르는 칸이 열리고, 등록하면 목록에 붙습니다. 병원이 달라도 한 목록으로 모이는 것을 보여주는 화면입니다.

    실제 서비스에서는 약사가 이 화면을 함께 보며 등록합니다. 약봉투 사진 인식은 다음 단계입니다.

    2. 오늘 복약 체크

    아침은 이미 8시 12분에 체크된 상태입니다. 점심 "먹었어요"를 누르면 초록색으로 바뀌고 지금 시각이 적힙니다. 한 번 더 누르면 취소됩니다.

    버튼을 화면 폭 전체로 키우고 글자를 20px 이상으로 잡은 이유는 어르신 휴대폰의 큰 글씨 모드와 같은 감각을 주기 위해서입니다.

    3. 가족 화면

    딸 박지은 씨가 보는 화면입니다. 2번에서 누른 결과가 그대로 반영됩니다. 안 먹은 시간대가 있으면 "아직이에요" 문구와 전화 버튼이 보이고, 모두 드시면 알림이 사라집니다.

    실제 계정 연결과 8시 알림 발송은 다음 단계이고, 지금은 같은 페이지 안에서 상태를 공유합니다.

    발표 때 보여주는 순서

    순서누르는 곳보여줄 것
    1약 등록 → 약 추가 → 이름 입력, 저녁 체크 → 등록하기병원이 달라도 한 목록
    2오늘 체크 → 점심 "먹었어요"초록색과 시간 기록, 위 약봉투에 도장
    3가족 화면점심이 반영됨. 저녁은 "아직"이라 알림과 전화 버튼
    4오늘 체크 → 저녁 "먹었어요" → 가족 화면알림이 사라지고 "모두 드셨어요"

    심사 항목 "생성형 AI 활용 적절성과 바이브코딩 구현 과정"에 답하기 위해 적었습니다.

    1. 강사가 준 CLAUDE.md로 시작. "claude.md 파일을 읽고 html 페이지 작성 시작해"라고 하자 디자인 방향 세 가지 중 하나를 고르라고 했고, 우리는 대화로 정하기(C)를 골라 "약봉투"를 첫 화면의 중심으로 삼았습니다.
    2. 6묶음 질문에 1일차 문제정의서를 보며 답했고, 기획서.md와 DESIGN.md가 만들어졌습니다.
    3. 뼈대 → 문제 → 하루 → 기능 → 시연 → 팀 순서로 한 단계씩 만들고 매번 브라우저에서 확인했습니다.
