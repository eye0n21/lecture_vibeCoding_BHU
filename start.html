설치 → 스타터 킷 → 첫 문장

미리 설치한 사람은 2번부터. Windows 기준입니다.

1VS Code + Claude Code

  • VS Code 실행 (없으면 code.visualstudio.com → Windows용)
  • 왼쪽 확장(Extensions) 아이콘 → 검색창에 Claude Code
  • Anthropic이 만든 것인지 확인하고 Install
  • 왼쪽에 생긴 Claude 아이콘 → 로그인 → 브라우저에서 학교 제공 계정

2스타터 킷 폴더

  • 스타터킷.zip 내려받기 (USB에도 있음)
  • 바탕화면에 압축 풀기 → 폴더 이름을 팀번호_아이템명으로 (예: 3조_오늘약)
  • VS Code → 파일 → 폴더 열기로 그 폴더를 열기 (파일 말고 폴더!)
  • Claude 아이콘을 눌러 채팅창 열기

3첫 문장

채팅창에 그대로 붙여 넣습니다.

claude.md 파일을 읽고 html 페이지 작성 시작해
